# Sacrament and Services Form Fields

- Mother - Contact Number (optional)
- Parents - Marriage Status
- Godparent 1 - Name
- Godparent 1 - Age
- Godparent 1 - Religion
- Godparent 1 - Address
- Godparent 2 - Name
- Godparent 2 - Age
- Godparent 2 - Religion
- Godparent 2 - Address

- Additional Godparent N - Age

- Additional Godparent N - Address
- Registration - Date of Baptism
- Registration - Time of Baptism
- Registration - Priest's Name
- Registration - Church Name
- Registration - Church Address
